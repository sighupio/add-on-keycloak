# Keycloak Add-On Module Release 2.3.1

Welcome to the latest release of `keycloak` add-on module of [`SIGHUP Distribution`](https://github.com/sighupio/distribution) maintained by team SIGHUP.

This release fixes a bug with the ServiceMonitor for Keycloak metrics.

## Component Images 🚢

| Component               | Supported Version                                                                                   | Previous Version |
| ----------------------- | --------------------------------------------------------------------------------------------------- | ---------------- |
| `keycloak-operated`     | [`v26.2.2`](https://github.com/keycloak/keycloak/releases/tag/26.2.2)                               | `unchanged`      |
| `keycloak-operator`     | [`v26.2.2`](https://github.com/keycloak/keycloak-k8s-resources/releases/tag/26.2.2)                 | `unchanged`      |

## Bug Fixes and Changes 🐛

- Fixed ServiceMonitor port for Keycloak metrics

## Update Guide 🦮

### Process

To upgrade this module from v2.2.0 to v2.3.0, execute the following:

```bash
KEYCLOAK_NS=<your_keycloak_namespace>

# Update Keycloak Operator and CRDs
kustomize build katalog/keycloak-operated | kubectl apply -n $KEYCLOAK_NS -f - 

```

N.B. This will not touch the Keycloak operator and instances, as this release only changes additional manifests added by this module.
